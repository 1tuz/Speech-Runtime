# Speech Runtime

Speech Runtime — проект локального общего сервиса для речевых моделей на macOS. Независимые приложения смогут явно выбирать модель и операцию, используя общий каталог и, где возможно, загруженные веса. Логика приложений и голосовых ассистентов остаётся у клиентов.

**Статус:** исследование и подготовка экспериментов; runtime и его API ещё не реализованы. Есть экспериментальный [ASR evaluation harness](experiments/asr_eval/README.md) и первое сравнение моделей на лицензированном наборе русских IT-встреч ([Veche-bench](experiments/pilot/ITERATION2.md), CC BY 4.0): 10 прогонов, WER/CER, терминные метрики, задержки стриминга, диаризация. Референсы там — сценарный текст, а не результат прослушивания, поэтому числа не объявлены бенчмарком; терминные и командные метрики по-прежнему требуют ручной калибровки.

**Что нового (2026-11-04):** Parakeet Ultra проверен на двух движках (FluidAudio CoreML и wavo GGUF: WER 10.42 % и 10.87 % на `dev`), на M4 ANE быстрее GPU в 1.7 раза; свип скользящего окна 0.5–11 с показал, что первый текст равен `chunk + right`, а задержка < 1 с возможна только при чанке 0.5 с ценой WER 35 %; `hypothesisChunkSeconds` в FluidAudio 0.17.7 не используется. Генеративный LoRA-корректор гипотез отклонён (WER 10.42 → 14.24 %). Пик памяти: ANE 40–58 МБ, GPU 770 МБ, CoreML 102 МБ. Разборы: [стриминг](experiments/pilot/STREAMING.md), [адаптация](experiments/pilot/ADAPTATION.md), [решения](docs/decisions.md).
