# Speech Runtime

Speech Runtime — проект локального общего сервиса для речевых моделей на macOS. Независимые приложения смогут явно выбирать модель и операцию, используя общий каталог и, где возможно, загруженные веса. Логика приложений и голосовых ассистентов остаётся у клиентов.

**Статус:** исследование и подготовка экспериментов; runtime и его API ещё не реализованы. Есть экспериментальный [ASR evaluation harness](experiments/asr_eval/README.md), но результатов сравнения моделей на русском IT-корпусе нет. До сравнения стенд требует проверки и исправлений.
