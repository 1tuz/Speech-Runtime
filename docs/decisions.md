Цель p95 < 1 с недостижима ни в одной проверенной конфигурации; прежнее объяснение через `minContextForConfirmation` опиралось на короткие реплики, где текст приходит в конце записи. |

Минус: нет потокового декодера — только batch по окнам. |
| CONFIRMED | В wavo-app потоковой транскрибации и захвата системного звука нет | Проверено по коду: движок получает запись целиком (`engine.rs` `SpeechModel::transcribe`, `on_piece` — только прогресс), cpal только микрофон. | CONFIRMED | Метрика WER по финальному тексту занижает деградацию стриминга; нужен замер видимого потока | `analyze_streaming.py` считает расхождение с `final` двумя способами: склейка partial подряд — 28.96 % при чанке 0.5 с и 1.26 % при 11 с; склейка по таймстампам — 31.69 % и 1.26 % (вставки 45 → 26). [V4](../research/wave2/V4-deps-licenses.md) сам содержит несовпадающие описания результата Rust-линковки: в итогах указана успешная сборка с дублирующимися символами и отдельная динамическая конфигурация, тогда как заголовочная сводка и старый отчёт формулируют отказ категорично. Ни одна из этих формулировок не доказывает невозможность Rust во всех конфигурациях. Проверять точные версии и команды перед решением.

[Исторический отчёт](report.md) и волны исследований сохраняют выводы своего времени. Его утверждения о необходимости трёх семейств воркеров, исключении всех готовых серверов и окончательном выборе транспорта не являются решениями текущей базы.
