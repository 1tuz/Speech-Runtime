Контракт унификации речевых задач

Клиентский и вычислительный наборы адаптеров независимы: приложения говорят только с контрактом, воркеры только с моделями. Добавление модели не требует изменений в приложениях, подключение нового приложения не требует изменений в вычислительных движках.
