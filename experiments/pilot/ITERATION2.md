# Итерация 2: Veche-bench как контрольный набор

Дата прогонов: 2026-10-28. Машина: Apple M5 Pro, 48 ГБ, macOS 27.0 (26A428),
Python 3.12 (`experiments/.venv`), Swift 6.4. Ни одно число здесь не является
подтверждённым бенчмарком: референсы — сценарный текст, а не результат
прослушивания человеком.

Связанные отчёты: [стриминг и задержки](STREAMING.md), [адаптация к терминам](ADAPTATION.md),
[раннеры и методика](../runners/README.md).

## Подготовка

`experiments/corpus/prepare_veche.py` режет встречу по границам реплик CSV,
пишет `manifest.tsv`, `metadata.jsonl` и RTTM. Правила, зафиксированные до прогонов:

- реплики короче 0.35 с отброшены (2 из 1290): Parakeet требует ≥ 0.3 с, и все
  модели должны видеть одинаковый набор;
- `dev` — три встречи (`2-one-to-one`, `5-it-product`, `7-bi-platform`), `test` —
  остальные шесть; разбиение по встречам, потому что реплики одной встречи зависимы;
- `mic_class=phone`, `register=R2`, `noise_class=clean` назначены скриптом и не
  проверены прослушиванием — заглушки для структуры метаданных, а не факты;
- `transcript_status=scenario_text_not_listened`, `rights_status=card_checked_no_human_signoff`:
  поэтому `preflight --benchmark` на наборе сознательно не проходит.

Итог: 1288 сегментов, 7010 с (116.8 мин), test 967 сегментов / 13 982 слова,
dev 321 сегмент, 83 вхождения терминов словаря `terms-v1` (366 терминов,
sha256 `8543fd9a…`).

## Что уже видно

1. **Языковая подсказка `language: .russian` в Parakeet подавляет латиницу.**
   Без подсказки v3 даёт `latin_form_accuracy` 26.7 % против 0.0 %, Ultra — 50.0 %
   против 0.0 %, term recall exact растёт с 9.3 % до 18.6 % (v3) и с 11.6 % до 34.9 %
   (Ultra). WER при этом почти не меняется (6.20 → 6.18; 5.79 → 5.89). Подсказка
   включает script-aware фильтрацию не-кириллических токенов — механизм описан в
   документации FluidAudio.
2. **Whisper лучше всех сохраняет латинские термины** (latin-form 60 %, term recall
   exact 46.5 %), но втрое дороже по времени на коротких репликах (RTF 0.43 против
   0.009 у Parakeet).
3. **GigaAM v3 даёт лучший WER (4.86 %)**, GigaAM Multilingual — лучший CER (1.74 %),
   но обе теряют латиницу: ML-модель CTC-чаровая и пишет всё кириллицей
   (`апи`, `кавка`), v3 смешивает формы (`Beckaind`).
4. **Qwen3-ASR 0.6B в 8-bit MLX даёт 12.27 % WER** — вдвое хуже остальных, с
   фактическими подменами (`backend → БКМ`, `регрессии → репрессиям`). Гипотеза:
   квантование или windowed-энкодер на коротких репликах; проверка на
   full-precision артефакте — отдельный прогон.
5. WER 5 % на этом наборе — верхняя оценка качества: текст читается со сценария,
   дикторов 21, шума в `data_simple` нет.

## Контроль на общем русском (FLEURS ru_ru test)

775 записей, 2.5 ч, официальные транскрипты, CC BY 4.0 (`google/fleurs`,
ревизия `70bb2e84…`). Аудио float32 16 кГц — раннер читает его без конвертации.

| Система | WER | CER |
|---|---|---|
| GigaAM v3 `e2e_rnnt` | 4.70 % | 1.66 % |
| Parakeet TDT v3 (без подсказки) | 6.18 % | 2.12 % |

Разрыв между GigaAM и Parakeet на общем русском (1.48 п.п.) и на IT-встречах
(1.32 п.п. на `data_simple`) одного порядка: на этом объёме нельзя утверждать,
что IT-домен меняет соотношение систем. Обе системы деградируют на Veche
относительно FLEURS, но у Parakeet это ноль (6.18 % на обоих наборах), а у
GigaAM — рост с 4.70 % до 4.86 %.

## Влияние сложности варианта

Те же встречи и те же тексты референсов, меняется только постобработка аудио
(`raw` → `simple` → `medium` (перекрытия) → `hard` (шум и эффекты)):

| Вариант | Parakeet v3 (без подсказки) | GigaAM v3 |
|---|---|---|
| `data_simple` | 6.18 % | 4.86 % |
| `data_medium` | 7.51 % | 6.89 % |
| `data_hard` | 11.26 % | 8.91 % |

Перекрытия речи добавляют 1.3–2.0 п.п. WER, шум — ещё 2.0–3.8 п.п. Порядок
систем при этом не меняется, но запас GigaAM сокращается с 1.3 до 2.4 п.п.
Прогонов на `data_raw` нет: он отличается от `simple` только паузами.

## Ограничения

- Референс — сценарный текст; расхождения «как написано» и «как произнесено»
  (числа, латиница, имена) человеком не выверены.
- 83 вхождения терминов на test — слишком мало для терминных выводов; интервал
  шире самого эффекта.
- `data_medium`/`data_hard` ещё не прогнаны.
- Диаризация: один движок, один порог, без сравнения с LS-EEND/Sortformer.
- Whisper шёл с `--language ru`, GigaAM — без языковых подсказок (у пакета их нет);
  это разные условия, и по терминам сравнение несимметрично.
