## Что изменилось после проверки

- **Опровергнуто:** «карточки Qwen3-ASR без русского» (русский есть), «Voxtral-MLX-6bit» и «GoodnotesIT litert» (не существуют), «у SpeechRail нет загрузчика», «standby выгружает веса», «FluidAudio Nemotron только английский», «у FluidAudio нет словарного биасинга».
- **Уточнено:** цифра «4 запроса → 97/191/284/378 мс» — самоотчёт автора, а не независимый замер; WER Parakeet 11.49 % — замер speech-swift на INT8 при официальных 5.51 %; Nemotron 9.17 % и 9.60 % — разные задержки одной таблицы.
- **Добавлено:** sandbox-транспорт (TCP работает, UDS — только в group container), `decoding_method` как свойство recognizer'а, а не сессии, и необходимость `prepare` как отдельной операции реестра.

Сводка всех расхождений — в [§8.3 отчёта](../../docs/report.md#83-противоречия-между-агентами-и-как-они-разрешены).
